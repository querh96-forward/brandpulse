# BrandPulse 产品需求文档（v0.1）

## 1. 背景

消费品牌每天面对新闻、公开网页、用户评价和社交讨论。人工监控容易漏掉高风险事件，
也难以快速结合品牌资料生成统一、可追溯的处置建议。

## 2. 目标用户

- 品牌市场人员
- 公关与客服团队
- 舆情分析人员

## 3. 核心目标

建立一条可以演示和评测的自动化闭环：

```text
公开数据采集
  → 清洗与去重
  → AI 情感及风险分析
  → 品牌知识库检索
  → 预警和报告
  → OpenClaw Channel 推送
```

## 4. MVP 功能

### P0：必须完成

1. CSV 数据导入
2. 一个 RSS 或公开网页采集器
3. 内容清洗与哈希去重
4. LLM 结构化分析
5. 风险评分与高风险预警
6. 舆情列表和详情 API
7. 日报生成
8. Docker Compose 启动
9. 自动化测试

### P1：岗位匹配能力

1. RAGFlow 品牌知识库
2. 带引用的处置建议
3. OpenClaw 自定义 Skill
4. Provider、Channel、Session 演示
5. React 数据看板

### P2：加分能力

1. 微信小程序预警端
2. SSE 实时任务进度
3. 在线 Demo
4. 模型效果和成本对比

## 5. 非目标

- 绕过平台验证码或反爬机制
- 大规模分布式爬虫
- 自训练基础大模型
- 在首版中实现复杂的多租户权限

## 6. 验收场景

1. 用户导入一批公开舆情数据。
2. 系统过滤重复内容并调用模型分析。
3. 高风险内容进入预警列表。
4. 系统从 RAGFlow 检索品牌资料。
5. 系统生成带引用的摘要和处置建议。
6. 用户通过 OpenClaw 查询日报并收到 Channel 消息。

## 7. 评测指标

- 数据导入成功率
- 去重率
- 情感分类准确率
- 风险类型准确率
- 高风险事件召回率
- 报告生成耗时
- API P95 响应时间
- 单条 AI 分析成本

所有指标必须来自可复现的测试，不为简历编造数据。

## 知识卡优化实验

Q2“设备报出 SEAL-07 后，用户首先应该怎么做？”的正确证据原本位于第 4 名，相似度为 `0.5159`。第一名虽然与 `SEAL-07` 相关，但只包含后续检测与维修政策，没有直接回答用户的首次操作。

新增 `bluecurrent_seal07_emergency_card.md` 后，正确证据提升至第 1 名，相似度提高至 `0.8109`，并明确包含“立即停止下潜任务并回收设备”。

优化后的指标：

- 可回答问题 Top 1 命中率：`7 / 8 = 87.5%`
- 可回答问题 Top 3 命中率：`8 / 8 = 100%`
- 范围外问题拒绝率：`0 / 2 = 0%`
- 最低相关证据分数：`0.5233`
- 最高范围外问题分数：`0.6400`

该实验说明，面向单一操作或规则编写自包含知识卡，可以减少长文本块中的语义稀释，比单纯调整全局相似度阈值更有效。

## 证据充分性判断冒烟测试

在向量召回 Top 3 之后，使用独立的 `EvidenceProvider` 判断候选文本是否明确包含回答问题所需的全部事实。

| 用例 | 预期 | 判断结果 | 支持证据 |
|---|---|---|---|
| Q2：SEAL-07 首次操作 | 放行 | `sufficient=true` | rank 1 |
| Q9：手机电池保修期 | 拒答 | `sufficient=false` | 无 |
| Q10：CEO 电话号码 | 拒答 | `sufficient=false` | 无 |

三条冒烟用例全部符合预期。加入证据判断后，本轮范围外问题拒绝率由 `0 / 2` 提升为 `2 / 2`。该结果只代表三条已验证用例，完整指标仍需在全部评测问题上运行。

## 端到端 RAG 舆情分析对照实验

使用 `qwen3.8-max`、`text-embedding-v4` 和 `v2-rag` Prompt，通过异步 Worker 完成正向与负向对照实验。

| 场景 | 证据审核 | 知识引用 | 最终表现 |
|---|---|---:|---|
| BC-D200 出现 `SEAL-07` | 充分 | 3 | 使用应急操作、用户处置和产品信息生成建议 |
| BlueCurrent 手机电池保修咨询 | 不充分 | 0 | 未注入内部知识，未编造保修期限 |

正向实验中，最终建议正确使用了停止下潜、回收设备、禁止绕过自检、`BLUE-SAFE-24`、3 个工作日初检和 A 批次检查等内部知识。负向实验仍完成一般舆情分析，但界面明确显示“未使用品牌内部知识”，并记录了证据不足原因。

## 基线结论

1. 纯向量检索已经具备语义召回能力，但当前结果不能依靠单一阈值完成无证据拒答。
2. 相关与无关分数发生明显重叠：`0.5233 < 0.6400`。若阈值足以过滤 Q9，也会过滤 Q3、Q6 和 Q7 的正确证据。
3. Q2 的目标证据未进入 Top 3，需要扩大候选集定位其实际排名。
4. 检索层应优先保证证据召回；范围外拒答还需要独立的证据充分性判断，不能把全部责任交给相似度阈值。
